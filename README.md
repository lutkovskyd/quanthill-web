# Quant Hill web 2.0

Веб-проект Quant Hill (вёрстка HTML/CSS).

## Структура

- `index.html`, `index-2.html`, `index-3.html`, `index-3-2.html` — страницы сайта
- `fonts/` — шрифты
- `foto/`, `logo/` — изображения и логотипы
- `screenshots/` — скриншоты

## Запуск

Откройте любой `.html` файл в браузере, либо запустите локальный сервер:

```bash
python3 -m http.server 8000
```

затем откройте http://localhost:8000

## Совместная работа

1. Склонируйте репозиторий: `git clone <url>`
2. Создайте ветку под свою задачу: `git checkout -b feature/название`
3. Вносите изменения, коммитьте и открывайте Pull Request.
